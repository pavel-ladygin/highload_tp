# Высоконагруженный сервис коротких вертикальных видео

## Тема
Тема курсового проекта – сервис коротких вертикальных видео. Реальный аналог – TikTok.

## Целевая аудитория
Tik Tok не публикует регулярную статистику MAU или DAU, но есть официальное заявление от 2021 года, в котором говорится о достижении 1 млрд пользователей за месяц [^1].
Целевая аудитория проектируемого сервиса – население России старше 12 лет. По данным Mediascope за июнь 2026 для целевой аудитории, DAU TikTok составляет около 27 млн человек, а MAU 49 млн человек [^2].

## Функционал
### Ключевые функции
1. Загрузка и публикация видео
2. Просмотр персонализированной ленты рекомендаций
3. Лайки, комментарии, счетчики просмотров
4. Отправка жалоб и модерация контента
5. Подписки на авторов и лента подписок

### Ключевые продуктовые решения
1. Публиковать можно только готовые видео продолжительностью не более 3 минут 
2. Видео сохраняется в трех вариантах качества: 480p, 720p и 1080p для разной скорости соединения
3. Счетчики просмотров и лайков могут работать с небольшой задержкой (около 1 минуты). При этом лайк пользователя должен быть сохранен без потерь и быть сразу виден пользователю, который его поставил 
4. Лента персонализируется на основе истории и длительности просмотра видео
